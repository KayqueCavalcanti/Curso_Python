# 🐍 Jornada de Aprendizado: Python 3 Completo

Repositório central criado para organizar meus estudos, códigos, laboratórios e desafios desenvolvidos ao longo do curso **Python 3 completo: PySide6, Django, Selenium, Regexp, Testes, TDD, POO e Design Patterns GoF**.

O objetivo deste monorepo é consolidar conceitos de arquitetura de software, boas práticas de programação (Clean Code) e ferramentas do ecossistema Python.

---

## 🛠️ Tecnologias, Conceitos e Ferramentas Praticadas

### 🔹 Fundamentos & Lógica Avançada (Em andamento)
* **Estrutura de Pastas:** Divisão clara entre conteúdos conceituais de suporte (`aulas`) e desafios práticos codificados por mim (`exercicios`).
* **Manipulação de Dados:** Uso avançado de dicionários, listas, estruturas condicionais e funções de cópia profunda (`deep copy`).
* **Tratamento de Erros:** Lançamento e controle de exceções customizadas utilizando `raise`.
* **Modularização:** Organização de sistemas em pacotes, submódulos e gerenciamento do ponto de vista do `__main__`.

### 🔹 Próximos Passos na Trilha:
* **Programação Orientada a Objetos (POO):** Classes, herança, polimorfismo e encapsulamento.
* **Padrões de Projeto (Design Patterns GoF):** Arquiteturas de código limpas e reutilizáveis.
* **Testes Automatizados (TDD):** Criação de testes unitários robustos antes da escrita do código.
* **Desenvolvimento Web & Automação:** Framework Django e automações web completas utilizando Selenium.
